# Hello Coder — Codex Integration

This file tells OpenAI Codex and other AGENTS.md compatible agents how to load Hello Coder skills.

---

## How to Use

At the start of your session, tell the agent:

- Frontend work: "Read and apply `profiles/frontend.md`"
- Backend work: "Read and apply `profiles/backend.md`"
- Fullstack work: "Read and apply `profiles/fullstack.md`"

Or load individual skills only:

- "Read and apply `skills/planning.md`"
- "Read and apply `skills/ui.md`"
- "Read and apply `skills/debug.md`"
- "Read and apply `skills/decisions.md`"
- "Read and apply `skills/workflow.md`"
- "Read and apply `skills/review.md`"
- "Read and apply `skills/testing.md`"

---

## What This Does

Once loaded, the agent will:
- Ask full questions before starting any feature
- Never assume without asking
- Follow professional UI standards
- Debug systematically
- Break tasks into small steps
- Self-review all code before presenting
- Run real tests and show real results
