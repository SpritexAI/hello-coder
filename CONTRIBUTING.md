# Contributing to Hello Coder

First off — thank you. Every contribution makes Hello Coder better for every developer who uses it.

---

## What You Can Contribute

### Fix or Improve an Existing Skill
If a rule in any skill file is unclear, incomplete, or could be better — open a PR with the improvement. Keep the same format and tone.

### Add a New Skill
If you have identified a common agent behavior problem that is not covered by any existing skill, you can propose a new one.

New skill requirements:
- Must solve a real, specific agent behavior problem
- Must have clear rules — not vague advice
- Must include bad examples and good examples
- Must follow the existing skill file format

### Add a New Profile
If you work in a specific domain (mobile, DevOps, data engineering etc.) and want a profile that combines skills for that role, open a PR.

### Report a Problem
If a skill rule causes unexpected or unhelpful agent behavior, open an issue describing:
1. Which skill file and which rule
2. What the agent did
3. What you expected it to do

---

## How to Submit a PR

1. Fork the repository
2. Create a new branch — `fix/skill-name` or `add/skill-name`
3. Make your changes
4. Open a pull request with a clear description of what you changed and why

Keep PRs small and focused — one skill or one fix per PR.

---

## Tone and Format Rules

All skill files must:
- Use plain, direct English — no fluff
- Use numbered lists for ordered steps
- Use bullet points for rules
- Include a Rule Summary section at the end
- Never be vague — every rule must be actionable

---

## Code of Conduct

Be respectful. We are all here to make AI agents less painful to work with.
